# Agent 设计组件系统分类大纲

> 定位：面向 Trae、Codex 一类 Agent 工作台的设计系统。以 Ant Design 式的通用组件体系为底座，叠加 Agent 专属组件与完整交互模式。
>
> 参考：[The Shape of AI](https://www.shapeof.ai/) 的 AI 体验模式分类。它侧重交互模式，并非可直接照搬的组件目录；本大纲按「设计基础 → 通用组件 → Agent 专属组件 → 交互模式」组织。

## 一、组件分类

| 分类 | 典型组件 | 核心目标 |
| --- | --- | --- |
| **01 设计基础 Foundations** | 色彩与语义色、字体、间距、圆角、阴影、动效、图标、明暗主题、密度、键盘焦点 | 统一桌面 IDE 与聊天界面的视觉和交互语言 |
| **02 通用基础组件 Primitives** | Button、Input、Select、Menu、Tabs、Tooltip、Popover、Modal、Drawer、Badge、Progress、Tree、Table、Toast | 提供类似 Ant Design 的通用组件底座 |
| **03 工作台与导航 Workspace** | Activity Bar、Sidebar、文件树、会话列表、顶部栏、面板布局、可拖拽分栏、命令面板、全局搜索、状态栏 | 构建多面板的 Agent 工作空间 |
| **04 对话与输入 Conversation** | Prompt Composer、消息气泡、富文本/Markdown 消息、附件、`@` 引用、`/` 命令、快捷建议、语音输入、追问卡片 | 支持提出任务、补充上下文和持续对话 |
| **05 上下文与配置 Context** | 文件/代码引用、选区引用、图片附件、上下文清单、模型选择器、模式切换、工具/连接器选择、参数面板 | 明确 Agent 将基于什么信息、以什么能力工作 |
| **06 Agent 执行过程 Execution** | 任务计划、步骤列表、运行状态、工具调用卡片、命令输出、进度时间线、子任务/子 Agent、暂停/继续/取消 | 让执行过程可见、可理解、可控制 |
| **07 产物与审阅 Artifacts** | 代码块、文件变更列表、Diff Viewer、终端结果、预览面板、引用来源、版本分支、接受/拒绝更改 | 支持检查、比较、采纳与撤销结果 |
| **08 权限、信任与安全 Trust** | 操作确认、权限请求、风险提示、成本/用量、数据与记忆设置、操作足迹、错误与恢复状态 | 明确 Agent 的权限边界与操作后果 |

## 二、交互模式库

组件是可复用的 UI 单元；模式是多个组件组合起来解决一个用户任务的方式。参考 Shape of AI 的引导、输入动作、调节、用户掌控、信任与身份识别等视角，单列模式库，避免将所有体验问题都抽象成独立组件。

| 模式分类 | 典型模式 |
| --- | --- |
| **启动与引导** | 空白页建议、示例任务、Prompt 模板、意图澄清 |
| **任务输入** | 开放式输入、选中代码后询问、内联操作、重新生成 |
| **任务调节** | 模型选择、Agent/Ask/Edit 模式、上下文范围、工具开关 |
| **人在回路** | 先展示计划、执行前确认、逐步审批、暂停与接管 |
| **结果验证** | 查看 Diff、运行测试、来源引用、回滚、更正后重试 |
| **信任与透明** | 工具调用足迹、风险说明、数据使用说明、成本反馈 |

## 三、V1 建设范围

优先跑通一条端到端链路：

**选择上下文 → 输入任务 → 查看计划 → 观察执行 → 审阅 Diff → 批准或回退。**

围绕该链路，优先建设以下 12 个标志性组件：

1. `Prompt Composer`：任务输入与发送。
2. `Context Chip / Context Picker`：引用和管理上下文。
3. `Model & Mode Switcher`：选择模型与工作模式。
4. `Conversation Message`：承载用户与 Agent 消息。
5. `Agent Status`：显示当前运行状态。
6. `Task Plan`：展示拟执行的步骤。
7. `Tool Call Card`：呈现工具调用与结果。
8. `Permission Request`：请求高风险操作授权。
9. `Terminal Output`：查看命令执行结果。
10. `File Change List`：汇总修改文件。
11. `Diff Viewer`：逐项审阅代码变更。
12. `Review Actions`：接受、拒绝或回退变更。

## 四、设计系统定位

- **通用性**：借鉴 Ant Design 的组件体系与一致性要求。
- **AI 体验**：借鉴 Shape of AI 对引导、控制和信任等交互模式的梳理。
- **领域特色**：重点定义 Agent 在代码工作台中如何与人协作，而不仅是聊天界面的视觉样式。
